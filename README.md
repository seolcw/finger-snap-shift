# Finger Snap Shift

Game Off 2026 entry (theme: **SHIFT**).

A giant finger snaps outside the world and shifts entire rows and columns of the grid.
Read the warning lines, dodge the hazards, and survive as long as you can.

## Play
Browser build on itch.io: _link coming soon_

## Controls
- Move: WASD / Arrow keys

## Tech
- Unity 6 (2D Built-in Render Pipeline), Web build
- Source code in this repository (Game Off requirement)

## Build (Web)
1. Switch platform to Web in Build Profiles
2. Player Settings > Publishing Settings: Compression Format = Gzip
3. Build, then zip the build folder so that `index.html` is at the zip root
4. Upload to itch.io as HTML ("This file will be played in the browser")
