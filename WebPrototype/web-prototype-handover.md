# Finger Snap Shift 웹 프로토타입 인수 노트 (5차 규칙 기준, 2026-11-20)

규칙 전체는 `Docs/DESIGN.md`가 기준이다. 3차의 글자 Shift(키 글자 ±N), Space 등록·입력 버퍼, 시프트 파동·스크롤 공격은 전부 없어졌다.

## 파일
- 결과물: `finger-snap-shift-prototype.html` (한 장). 원본은 `src/`, `node src/build.js`로 합친다.
- `src/layoutRules.js` 마스크, 줄 정의(`lines`), 단어 정렬 계산(`bestAlign`), 시작 배치 검사(`check`), 단어 목록 검사(`checkWordList`)
- `src/layouts.json` 시작 배치 (3차와 같은 배치, 5차 규칙도 통과)
- `src/attackPatterns.json` 수치: config, 슬라이더, 페이즈별 단어·공격·손 HP·배율, 단어별 마법(`spells`), 공격별 base·쿨다운·예고 배율
- `src/game.js` BoardModel / PlayerController / WordSystem / Perimeter / HandBrain / HandController / Game
- `src/simtest.js` 헤드리스 봇 시뮬레이션. 봇은 목표 자리마다 "글자를 앞에서부터 하나씩 BFS로 옮기는" 풀이를 만들어 가장 짧은 것을 고른다.
- `src/verify-rules.js` 5차 규칙 검증(줄 돌리기, 한 줄 정렬 발동, 글자 구성 불변, 사망 시 손 HP 절반 회복, 처음부터 승리까지)
- `src/generate-layouts.js` 규칙을 통과하는 새 시작 배치 만들기

## 5차에서 정한 세부
- Shift+←→는 행, Shift+↑↓는 열을 그 방향으로 한 칸 순환. 플레이어 자리는 그대로. 누르고 있으면 0.2초마다 반복.
- Shift를 누른 채 방향키를 누르고 있다가 Shift를 떼면 그때부터는 이동으로 바뀐다.
- 단어 판정은 판이 바뀔 때마다(플레이어 돌리기, 손 줄 섞기) 두 판 모두에서 한다.
- 다음 단어는 페이즈 목록 순서대로. 이미 판에 완성돼 있는 단어는 건너뛴다.
- 마법: 0.9초. 앞 55%는 맞춘 줄 가운데서 손으로 날아가고, 닿는 순간 손이 Hurt(번쩍 + 뒤로 튐), 피해 숫자가 뜬다. 피해 자체는 완성 즉시 적용.
- 손은 마법을 맞으면 0.8초 + 연출 절반만큼 멈춘다(예전 ESC 2초 멈춤을 대신함).
- 페이즈 클리어·승리 화면은 마법 연출이 끝난 뒤에 뜬다.
- 줄 섞기 n은 항상 1칸. 플레이어가 맞춘 줄을 가로지르는 줄에 가산점.

## 봇 시뮬레이션 (5차 수치)
| 봇 | 결과 |
| --- | --- |
| 항상 피함, 0.22초마다 행동 | 4판 모두 승리, 1.5~2분, 사망 0~1 |
| 항상 피함, 0.6초마다 행동 | 4판 모두 승리, 4.5~5.5분, 사망 0 |
| 70% 피함 (verify-rules) | 승리, 약 1.5분 |

봇은 퍼즐을 최적으로 푼다. 사람은 생각할 시간이 들어서 훨씬 오래 걸리고, 그만큼 공격을 더 받는다. 난이도는 실제 플레이로 맞춰야 한다.
